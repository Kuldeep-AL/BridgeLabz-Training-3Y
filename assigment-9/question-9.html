Three principles / Responsive design

Make the web
fit the moment.

01

Fluid layouts

Let the layout use available space instead of assuming a fixed screen width.

.layout {
  display: grid;
  grid-template-columns:
    repeat( auto-fit,
    minmax(16rem, 1fr) );
}
02

Flexible media

Keep images inside their containers so they scale down without overflowing.

img,
video {
  max-width: 100%;
  height: auto;
}
03

Breakpoints

Shift the design when the content benefits from a new arrangement.

@media (max-width: 600px) {
  .layout {
    grid-template-columns: 1fr;
  }
}
