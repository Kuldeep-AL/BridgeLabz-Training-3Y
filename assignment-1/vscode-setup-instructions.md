# VS Code Setup Instructions (HTML/CSS/JS)

1. Install VS Code

- Download and install from https://code.visualstudio.com/ and follow the installer.

2. Recommended extensions

- Live Server — launch a local development server with live reload.
- Prettier - Code formatter — consistent code formatting.
- ESLint — JavaScript linting and error checking.
- HTML CSS Support — better HTML/CSS autocompletion.

3. Basic configuration

- Open the folder `assignment-1` in VS Code.
- Install the extensions listed above from the Extensions view.
- Open an HTML file and click "Go Live" (bottom-right) to start Live Server.

4. Take a screenshot

- On Windows: open VS Code, press `Win+Shift+S` to capture, save the image as `vscode-setup-screenshot.png` inside the `assignment-1` folder.
